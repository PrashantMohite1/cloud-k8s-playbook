# cloud-k8s-playbook

A community-driven repository containing cloud-managed Kubernetes setup guides, Terraform examples, and production-focused DevOps notes.

## Structure

```
cloud-k8s-playbook/
├── aws-eks/       # implemented — see aws-eks/README.md
├── azure-aks/     # planned
├── gcp-gke/       # planned
└── common/        # cross-cloud Terraform/HCL reference docs
```

Only `aws-eks/` is built out right now. `azure-aks/` and `gcp-gke/` are placeholders for future work.

## Getting started

Head to [aws-eks/README.md](aws-eks/README.md) for the directory guide, quickstart, and commands to spin up a test cluster and deploy a workload to it.
